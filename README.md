# 🌦️ Weather Dashboard

A modern, responsive **Weather Dashboard** built with **HTML, CSS, and JavaScript** that provides real-time weather information using a weather API.

Users can search for any city and instantly view important weather details such as temperature, humidity, wind speed, atmospheric pressure, visibility, and current weather conditions through a clean and intuitive interface.

---

## 🚀 Features

### 🌍 Live Weather Updates

* Fetches real-time weather data using a weather API.
* Displays accurate and up-to-date weather information.
* Supports weather searches for cities around the world.

### 🔎 City Search

* Search for any city using the search bar.
* Quickly retrieve the current weather conditions for the selected location.
* Displays location details along with weather information.

### 📊 Detailed Weather Information

The dashboard provides:

* 🌡️ Current Temperature
* 🤗 Feels Like Temperature
* 💧 Humidity
* 💨 Wind Speed
* 🌤️ Weather Condition
* 🎚️ Atmospheric Pressure
* 👁️ Visibility
* 📍 Location Details

### 🎨 Interactive User Interface

* Clean and modern design.
* Easy-to-use search functionality.
* Weather cards with intuitive icons.
* Clear presentation of weather information.

### 📱 Responsive Design

The dashboard is designed to work smoothly across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablets

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Weather-Dashboard.git
```

### 2. Navigate to the Project Directory

```bash
cd Weather-Dashboard
```

### 3. Configure the API

Open `script.js` and add your weather API key:

```javascript
const API_KEY = "YOUR_API_KEY";
```

> ⚠️ **Important:** Never commit your real API key to a public GitHub repository.

For a production project, store sensitive API credentials securely using environment variables or a backend service.

### 4. Run the Project

You can simply open:

```text
index.html
```

in your browser.

For the best development experience, you can also use the **Live Server** extension in VS Code.

## 🔑 API Configuration

This project requires a weather API to retrieve real-time weather information.

### Steps:

1. Choose a weather API provider.
2. Create an account.
3. Generate an API key.
4. Add the API key to your JavaScript configuration.
5. Start the application.

Example:

```javascript
const API_KEY = "YOUR_API_KEY";
```

Make sure your API key is not uploaded to GitHub.
